
# Victor 9000 Talking Startrek

The Victor 9000 debuted alongside the IBM PC as an early DOS machine. When it was developed the IBM PC didn't yet exist, so by definition it's not PC compatible. The Victor supported audio as a default feature, but very few programs took advantage of the capability. One young teenager ported the Basic Startrek game to the Victor, adding in audio capabilities. 

You can relive the excitement of hearing a human's voice coming out of a speaker here https://pauldevine.github.io/victor9k-web-emulator/
